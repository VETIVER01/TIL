## 2. DB 연결하고 메시지 저장하기

데이터베이스(DB)는 데이터를 저장하는 곳이다. 테이블은 그 안에 있는 표다. `msg` 테이블의 한 행에는 채팅방, 보낸 사람, 내용, 보낸 시간이 들어간다.

- `connect()`로 DB 파일을 열고, `cursor()`로 SQL을 실행할 커서를 만든다. 수업에서는 커서 이름을 `마우스`로 정했다.
- `CREATE TABLE IF NOT EXISTS`는 테이블이 없을 때만 만든다.
- `execute()`는 SQL 명령을 실행한다. `INSERT INTO`로 행을 추가하고 `commit()`으로 변경을 확정한다.

```python
import sqlite3 as db

db저장소 = db.connect("kakao.db")
마우스 = db저장소.cursor()
```

## 3. 빈 메시지 처리하기

`st.chat_input()`은 메시지를 보내기 전에는 `None`을 돌려준다. `메시지 != ""`는 `None`일 때도 참이어서 뒤의 `메시지.strip()`에서 오류가 났다. 앞에서 `메시지`를 먼저 확인하면 값이 있을 때만 `strip()`을 호출한다. 공백만 입력한 경우도 걸러진다.

```python
메시지 = st.chat_input("메시지를 입력")

if 메시지 and 메시지.strip():
    마우스.execute("""
        INSERT INTO msg (채팅방, 보낸사람, 내용, 보낸시간)
        VALUES (?, ?, ?, ?)
    """, (채팅방이름, 나, 메시지.strip(), 보낸시간))
    db저장소.commit()
```

이 예제는 `msg` 테이블이 있고, 방 이름·보낸 사람·시간을 변수에 넣어 둔 상태에서 실행한다. SQLite의 `?`에는 뒤에 전달한 값을 순서대로 넣는다. 메시지에 작은따옴표가 있어도 글자 그대로 저장할 수 있다.

## 4. 선택한 방의 채팅만 보여주기

`st.selectbox()`로 방을 고른 뒤, 같은 방 이름을 메시지 저장과 조회에 사용한다. `WHERE`는 선택한 방의 행만 고르고 `ORDER BY`는 보낸 시간순으로 정렬한다. `fetchall()`로 가져온 행은 반복문에서 하나씩 꺼낼 수 있다.

```python
마우스.execute("""
    SELECT 보낸사람, 내용, 보낸시간
    FROM msg
    WHERE 채팅방 = ?
    ORDER BY 보낸시간
""", (채팅방이름,))

for 보낸사람, 내용, 시간 in 마우스.fetchall():
    with st.chat_message(보낸사람):
        st.write(보낸사람, 시간)
        st.write(내용)
```

`?`가 하나면 `(채팅방이름,)`처럼 뒤에 쉼표를 붙여 값 하나가 들어 있는 튜플로 전달한다.

## 5. 회원가입과 로그인 조회

- 회원가입에서는 아이디, 이름, 전화번호 등의 입력을 받고 가입 버튼을 눌렀을 때 `members` 테이블에 저장하는 흐름을 실습했다.
- 로그인 화면과 가입 화면은 `st.tabs()`로 나눈다. 두 탭에 같은 이름의 입력창이 있으면 `key`를 다르게 지정해 구분할 수 있다.
- 로그인 실습처럼 한 사람을 찾을 때는 `fetchone()`을 쓴다. 일치하는 행이 없으면 `None`이 나온다.
- `type="password"`는 입력 화면의 글자만 가린다. 실제 서비스에서는 비밀번호를 평문으로 저장하지 않고 해시로 저장해야 한다.
